# 50 Screens — Grant Discovery Infrastructure

This is the "how to hunt well" layer — durable, reusable knowledge about *where opportunities
live*, separate from `opportunities.md` (which is the project's own pipeline/tracker). Everything
here is general-purpose: it stays useful even as the project's specific status changes. Verify
current URLs/details with `WebSearch` if it's been a while — this list is dated **2026-09-20**.

The core failure mode this file exists to prevent: treating grant-hunting as a one-time lookup
instead of a recurring habit. Several of the sources below are things the team is already
*receiving* passively (newsletters landing in the inbox) without anyone mining them.

---

## Databases & aggregators

| Source | What it is | Use it for |
|---|---|---|
| **[IDA Documentary Grants Directory](https://www.documentary.org/funding)** | The International Documentary Association's own funder directory. The single most authoritative index for documentary-specific funding. | First stop for any documentary-funder search. |
| **[Documentary Funding Vault](https://docfundingvault.com/guide/how-to-fund-a-documentary)** | Continuously-updated database, 150+ documentary funding opportunities, each verified against the funder's own page. Tracks deadlines, amounts, eligibility across 12 regions. | Broader sweep than IDA's directory; good for catching regional/international funds. |
| **[FindGrants.io](https://findgrants.io/grants/focus/documentary)** | Newer database with AI-assisted grant matching. | Useful for a second opinion, but newer/less established than IDA or the Vault — verify anything it surfaces against the funder's own site before trusting it. |
| **[FilmFreeway](https://filmfreeway.com/)** | Not just a database — the actual submission platform many labs and grants use. | **Most actionable item here.** Create a project account, follow/favorite relevant programs. FilmFreeway then emails automatically when a followed program's call opens *and* again before its deadline — this turns deadline-tracking into something that happens without anyone remembering to check. |
| **[Film Impact Georgia](https://www.filmimpactgeorgia.org/grants)** | Grants and labs specific to Georgia. | Directly relevant now that Atlanta is a named focus (see the Aug 29 scope expansion in `project-facts.md`). |
| **[Southern Documentary Fund](https://southerndocumentaryfund.org/programs/filmmaking-grants-2/)** | Regional funder + resource hub for docs made in/about the American South. | Already in the pipeline (`opportunities.md`); its resource pages are also worth periodic browsing beyond the one grant line. |
| **[Wrapbook: Best Filmmaking Grants for People of Color](https://www.wrapbook.com/blog/grants-for-people-of-color)** | Curated list article. | Starting point for the Black-owned/minority-owned Atlanta angle — cross-check anything found here the same way as any WebSearch result (verify against the funder's own page). |

## Communities

| Source | What it is | Use it for |
|---|---|---|
| **[Black Public Media](https://blackpublicmedia.org/for-media-makers/)** | Simultaneously a funder, a training program, and a community for Black media storytellers. Runs a 3-month Incubator and **PitchBLACK** — an annual pitch competition for Black independent documentary filmmakers, with production funding up to **$150,000**. | **The strongest single find in this whole file.** Directly matches the Aug 29 scope expansion toward Black-owned/minority-owned theaters in Atlanta. Should be screened against `opportunities.md`'s eligibility profile as a near-term priority, not just filed here. |
| **National Black Programming Consortium (NBPC)** | Nonprofit supporting Black filmmakers since 1979. | Same lane as Black Public Media — a second, independent point of entry into that funding/community network. |
| **The D-Word** | Long-running documentary filmmaker forum. | The applied-wisdom layer a static funder list can't give — "has anyone actually applied to X, what's it really like." Worth checking before investing real time in an unfamiliar program. |
| **IDA membership** (distinct from the free newsletter) | ~2,800+ members, a searchable member directory, regional salons (Impact Circle, NYC/LA), a documentary screening series. | The team currently only receives IDA's newsletter passively — actual membership is a concrete, unclaimed step that opens the member directory and salons. |
| **Art House Convergence** | Industry body for arthouse/independent exhibitors. **Already a live relationship** — intro call with Lela Meadow-Conner happened; see `project-facts.md`. | Currently framed only as a theater-distribution contact. Industry bodies like this also circulate funding intelligence — worth explicitly asking Lela what's live in that world, not just pursuing it for Nouveau Roadshow partnerships. |

## How to actually use this file
1. **Quarterly:** pull the current-season No Film School list; screen new entries against the
   eligibility profile in `opportunities.md`; add real fits to the pipeline.
2. **Monthly-ish:** skim the newsletters already arriving (IDA Weekly, Film Independent, From
   the Heart Productions) specifically for opportunities, not just general industry news.
3. **When scope changes** (as it did Aug 15 and Aug 29): re-screen this whole file — a scope
   shift can make previously-irrelevant sources (like Black Public Media) suddenly the most
   important thing in it.
4. **Before investing real drafting time** in an unfamiliar program: a quick check of The D-Word
   or a direct ask in a relevant community can save hours versus discovering a bad fit mid-draft.
